# API Documentation Generator Workflow

This workflow generates comprehensive API documentation from your codebase.

## Steps

1. Ask the user which API/codebase they want to document

2. Review the API documenter skill instructions:
   - Read `.agent/skills/skills/api-documenter/SKILL.md` for detailed instructions

3. Analyze the codebase structure and identify API endpoints, functions, and classes

4. Generate documentation following OpenAPI/Swagger standards (if REST API) or appropriate format

5. Create documentation files with:
   - Endpoint descriptions
   - Request/response schemas
   - Authentication requirements
   - Example requests and responses
   - Error codes and handling

6. Present the generated documentation to the user
