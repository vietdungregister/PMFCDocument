# UI/UX Pro Max Workflow

This workflow provides professional UI/UX analysis and recommendations.

## Steps

1. Ask the user which UI/UX aspect they want to analyze:
   - Existing design files (HTML, CSS, Figma exports)
   - User flow diagrams
   - Wireframes or mockups
   - Accessibility concerns

2. Review the provided materials

3. Analyze based on UI/UX best practices:
   - Visual hierarchy and layout
   - Color theory and contrast
   - Typography and readability
   - Accessibility (WCAG compliance)
   - User flow and navigation
   - Mobile responsiveness
   - Loading states and feedback
   - Error handling and validation

4. Generate a comprehensive report with:
   - Current state assessment
   - Identified issues and pain points
   - Prioritized recommendations
   - Before/after mockups (if applicable)
   - Implementation suggestions

5. Present findings and discuss next steps with the user
